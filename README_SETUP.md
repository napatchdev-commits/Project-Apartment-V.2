# คู่มือการติดตั้งและตั้งค่าระบบ (Vercel & Supabase Setup Guide)

คู่มือนี้แนะนำขั้นตอนการนำตัวโครงการขึ้นใช้งานจริงบน **Vercel** และเชื่อมต่อเข้ากับฐานข้อมูล **Supabase**

---

## ส่วนที่ 1: การตั้งค่า Supabase (Database Setup)

ให้เข้าไปที่หน้า Dashboard ของ [Supabase](https://supabase.com/) จากนั้นทำตามขั้นตอนดังนี้:

1. **สร้างโครงการใหม่ (New Project)**:
   - ตั้งชื่อโครงการ (เช่น `my-hostel-system`)
   - กำหนดรหัสผ่าน Database Password (จดจำไว้)
   - เลือกภูมิภาคเป็น **Singapore** (เพื่อลดความหน่วงข้อมูล)

2. **สร้างตารางและฟังก์ชัน (SQL Run)**:
   - เข้าเมนู **SQL Editor** จากแถบเมนูซ้ายมือ
   - คลิกปุ่ม **New query** (เพื่อสร้างหน้าคีย์คำสั่งว่างเปล่า)
   - เปิดไฟล์ [supabase_setup.sql](./supabase_setup.sql) ในโฟลเดอร์โครงการนี้ แล้วคัดลอกเนื้อหาทั้งหมดไปวาง
   - กดปุ่ม **Run** เพื่อสร้างตารางทั้งหมด อนุมัติสิทธิ์ RLS คีย์ข้อมูลผู้ดูแลเริ่มต้น และสร้าง Bucket สำหรับฝากรูปภาพ

---

## ส่วนที่ 2: การนำขึ้นใช้งานบน Vercel (Frontend Deployment)

ระบบนี้ขับเคลื่อนผ่าน static client-side ทำให้การจัดทำ Deploy บน Vercel ทำได้อย่างง่ายดายดังนี้:

1. นำโฟลเดอร์โค้ด Next.js นี้ (`โปรเจค ห้องเช่าใหม่`) อัปโหลดขึ้นสู่ **GitHub** (หรือ Git Repository ที่คุณต้องการ)
2. เข้าสู่หน้าหลัก [Vercel Dashboard](https://vercel.com/) และล็อกอิน
3. คลิก **Add New** -> **Project**
4. เชื่อมต่อบัญชี GitHub ค้นหา Repository ที่ได้นำขึ้นไว้ แล้วกด **Import**
5. ในขั้นตอนตั้งค่า Build (ข้ามส่วนของ Environment Variables ไปได้เลย เนื่องจากเราจะเซ็ตผ่านเว็บบอร์ดเป็นรายครั้ง)
6. คลิกปุ่ม **Deploy** และรอสร้างเซิร์ฟเวอร์เสร็จสิ้นภายใน 1-2 นาที

---

## ส่วนที่ 3: การเชื่อมต่อระบบครั้งแรก (First-Time Connection Wizard)

1. คลิกเข้าสู่ลิงก์ URL ที่ Vercel มอบให้ (เช่น `https://your-hostel.vercel.app`)
2. ระบบจะตรวจพบคอนฟิกที่ยังว่างเปล่าและพาคุณเข้าสู่ **หน้าจอวิซาร์ดตั้งค่า Supabase** โดยอัตโนมัติ
3. ให้กรอกคีย์ต่อไปนี้ (หาได้จากหน้า Supabase Dashboard > Project Settings > API):
   - **Supabase URL**: คัดลอกช่อง URL โครงการ
   - **Supabase Anon Key**: คัดลอกคีย์ anon public
4. คลิกปุ่ม **บันทึกการเชื่อมต่อและเริ่มต้นใช้งาน**
5. ระบบจะทำการโหลดข้อมูลและนำทางเข้าหน้าล็อคอิน โดยข้อมูลบัญชีสำหรับเริ่มต้นใช้งานคือ:
   - **ผู้ดูแลสูงสุด (Super Admin)**: Username: `superadmin` / Password: `admin`
   - **ผู้ดูแลทั่วไป (Admin)**: Username: `admin` / Password: `admin`
   - **พนักงานคีย์ข้อมูล (Staff)**: Username: `staff` / Password: `staff`
   *(คุณสามารถเปลี่ยนรหัสผ่านได้ในฐานข้อมูล หรือตั้งค่าหอพักได้ผ่านหน้า /admin/settings)*
